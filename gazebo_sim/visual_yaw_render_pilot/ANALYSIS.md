# 离线渲染的中间视角能提供什么

输入提交 `d6cee58e4536763e7e6019259ffc6d7b84f77846`。已核对 SDF 和 13 个 PNG 的 SHA256、图像尺寸、各相机标签与 SDF 朝向、原始时间戳。背景中部分材质缺失与 WSL 正常 house 场景相同。该试拍只有一个 02 训练区位置，视角为 −90° 到 +90°，每 15° 一张。

对这些图像用 burger_cam 的广角投影转换到角度图，采用已记录的双向 SIFT 和一致性条件。按 15°、30°、90° 计算所有正向图像对：

| 相差角度 | 通过 / 总数 | 通过对的平均角误差 |
| --- | ---: | ---: |
| 15° | 11/12 | 0.34° |
| 30° | 4/11 | 0.65° |
| 90° | 2/7 | 2.30° |

用 15° 或 30° 的有效边离线相加，−90°→0° 得到 91.98°，0°→+90° 得到 91.92°。第二段用 45°→75° 的有效边跨过 60°→75° 的缺匹配。这是固定相机组的可观测性结果，尚未验证模型泛化、移动中的视角对齐或闭环。
