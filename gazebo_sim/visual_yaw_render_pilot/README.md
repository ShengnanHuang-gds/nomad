# 固定朝向渲染试拍

在 `house_run_02` 训练区域出生点附近放了 13 个静止广角相机，朝向从 -90° 到 +90°，每 15° 一张。没有开车，也没有用 05、06、07。场景和镜头来自当前 WSL 安装的 `turtlebot3_gazebo` 房屋世界与 `burger_cam` 模型，哈希写在 `manifest.json`。`camera_model_source_sha256` 与之前实车探针用的模型 SDF 相同。

13 张都是 320×240，像素各不相同。从 -90° 到 +90° 画面连续变化：绿门从画面左侧移到右侧后离开，随后看到木墙和窗口。抽看的 -90°、-45°、0°、+45°、+90° 都没有被一面墙铺满。

日志里 `Wood_Floor_Dark.jpg` 和 `Maple.jpg` 找不到，地面是灰的。实车启动同一房屋时也有这两条找不到文件的记录，这次没有改资源路径。
